# Testing an Event Booking Software (Case Study)

This is a Case Study of an Event Booking System implemented in **Java** programming language. The focus of the Case Study is testing the software using **JUnit** and **Mickito** libraries.

- Tested a command-line-based program consisting of multiple Java classes for event and resource scheduling.
- Designed and implemented 20 test cases using equivalence partitioning and boundary value analysis (BVA) for black-box testing.
- Performed unit and structural testing on classes, including statement and branch coverage analysis.
- Developed Control Flow Graphs and identified test paths, including exception-handling paths.
- Prepared defect reports and test results by comparing expected and actual outcomes.
- Identified defects involving maximum index values, incorrect boundary conditions, and nullified IDs, with differences found in 6 of 17 BVA-based test cases.
